## 行业痛点

绝大多数嵌入式设备的身份认证发生在固件层——控制了软件的人，也就控制了设备身份。对于基于 FPGA 的工业设备和成本敏感的物联网终端，整板抄板是一个长期存在的商业问题，而现有对策都不理想：

- **比特流加密**：主流 FPGA 系列的比特流加密已有公开的侧信道攻击研究。
- **外挂认证芯片**：成本低，但总线暴露，易被中间人攻击绕过。
- **完整安全子系统**（TPM、安全元件、商用 RoT IP）：其架构与定价面向高保障等级芯片，放不进真正发生抄板的那类设备的面积、功耗与授权预算。

AURA 针对的正是这个空档：把身份绑定直接放进逻辑本身，且面积小到可以与主应用共存。

## AURA 是什么，不是什么

AURA 是**身份与状态锚点**，不是密码运算引擎，也不是 TPM 的替代品。

**它提供：** 设备身份绑定、克隆检测、软件无法清除的硬件隔离态、SEU 异常检测。

**它不提供：** 通用加解密、安全元件级别的密钥存储、认证过的密码算法库，目前也不具备 CC 保障等级。

与相邻技术的定位对比：

| | 面积量级 | 可嵌入 MCU / 小型 FPGA | 主要功能 |
|---|---|---|---|
| TPM 2.0 | ~50,000 GE | ✗ | 完整安全子系统 |
| 商用 RoT IP（tRoot / RT 系列 / PUFrt 类） | 数千 GE | 部分 | 启动完整性 + 密钥管理 |
| 单独 PUF 宏 | ~10,000 GE | 部分 | 不可克隆密钥源 |
| 外挂认证芯片 | 独立器件 | ✓ | 挑战应答认证（总线暴露） |
| **AURA（基础版）** | **182 GE** | **✓** | **身份绑定 + 隔离态** |
| **AURA（SCA加固版）** | **~280–320 GE** | **✓** | **同上，增加侧信道加固** |

本表比较的是面积与适配性，**不是功能等价性**。AURA 处于不同的层级：它不是在保障等级上与 TPM 竞争，而是面向那些从一开始就装不下 TPM 的设计。

**门数口径：** 182 GE 为基础版 HRoT，FPGA 实测（Vivado 2023.2，Artix-7 35T：46 LUT + 22 FF）。~280–320 GE 为四层 SCA 全部启用（FPGA 实测）。28nm ASIC 估算约 300–500 GE——为估算值，非流片实测。

## 核心机制

在标准二进制 CMOS 上实现三态编码——无需特殊工艺。

| 状态 | 含义 | 行为 |
|---|---|---|
| `2'b01` | 合法 | 正常运行 |
| `2'b10` | **隔离** | 访问阻断；**授权方可凭凭证验证恢复** |
| `2'b11` | 非法 / 告警 | 检测到异常或 SEU 事件 |

**关键特性：** `2'b10` 一旦进入 MAC 链，任何软件指令都无法清除。恢复只能通过硬件定义的路径完成凭证验证。

**这是刻意设计，且并非变砖。** 对产品方而言，隔离事件是一个有明确恢复流程的可服务状态——因为可恢复，它可以作为售后流程运营，而不是一次退货。对持有克隆件的攻击者而言，不存在任何软件层面的回路。

## 四层侧信道加固

| 层 | 机制 | 针对 |
|---|---|---|
| L1 | 掩码 LFSR | 差分功耗分析（DPA） |
| L2 | 双轨逻辑 | DPA、故障注入、SEU（0 周期检出） |
| L3 | 恒定时间 MAC | 时序侧信道 |
| L4 | 随机延时插入 | DPA 轨迹对齐 |

四层全部在 RTL 层实现，不依赖固件。

> **验证状态说明。** 上述机制已实现并通过功能仿真验证。**物理侧信道评估（TVLA，依据 ISO/IEC 17825）正在进行中。** 在该数据公布之前，任何"已实测抗攻击能力"的表述都不应被视为已验证。我们选择主动写明这一点，而不是等评估方自己发现。

## 目标应用

**FPGA 整机制造商** — 工业控制器、仪器仪表、医疗与检测设备等面临整板抄板问题的产品。可直接部署在现有硬件上，无需重新流片。**这是我们当前的首要方向。**

**物联网与嵌入式芯片** — 智能锁及高安全终端，尤其是装不下完整安全子系统的面积/功耗预算场景。欧盟 EN 18031 已于 2025 年 8 月在无线电设备指令（RED）下开始适用；SESIP L2 为已支持的认证路径。

**汽车电子** — 四层 SCA 加固对应 ISO 21434 的硬件前置要求，对 ECU 硅面积的增加极小。认证周期较长，作为战略路径而非近期路径推进。

**RISC-V SoC 项目** — AMBA APB 集成封装开发中。
