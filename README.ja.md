## 課題

多くの組込み機器では、認証がファームウェア層で行われています。つまり、ソフトウェアを掌握した者が機器のアイデンティティを掌握できてしまいます。FPGA ベースの産業機器やコスト制約の厳しい IoT 端末において、基板レベルのクローン（コピー基板）は継続的な事業上の問題ですが、既存の対策はいずれも十分ではありません。

- **ビットストリーム暗号化** — 主要 FPGA ファミリについては、サイドチャネル脆弱性が公表されています。
- **外付け認証チップ** — 安価ですが、バス上での中間者攻撃により回避され得ます。
- **フルセキュリティサブシステム**（TPM、セキュアエレメント、商用 RoT IP）— 高保証シリコン向けに設計・価格設定されており、クローンが実際に発生している機器の面積・電力・ライセンス予算には収まりません。

AURA はこの空白領域を対象とします。アプリケーションと共存できる面積で、identity binding をロジックそのものに組み込みます。

## AURA であるもの／ないもの

AURA は**アイデンティティと状態のアンカー**であり、暗号演算エンジンでも TPM の代替でもありません。

**提供するもの：** 機器の identity binding、クローン検知、ソフトウェアから解除できないハードウェア隔離状態、SEU 異常検知。

**提供しないもの：** 汎用暗号処理、セキュアエレメント相当の鍵保管、認証済み暗号ライブラリ、および現時点での CC 保証等級。

隣接技術との位置づけ：

| | 面積規模 | MCU / 小規模 FPGA への内蔵 | 主機能 |
|---|---|---|---|
| TPM 2.0 | ~50,000 GE | ✗ | フルセキュリティサブシステム |
| 商用 RoT IP（tRoot / RT シリーズ / PUFrt 系） | 数千 GE | 一部可 | ブート完全性 + 鍵管理 |
| PUF マクロ単体 | ~10,000 GE | 一部可 | 複製不能な鍵源 |
| 外付け認証チップ | 独立部品 | ✓ | チャレンジレスポンス認証（バス露出） |
| **AURA（ベース版）** | **182 GE** | **✓** | **identity binding + 隔離状態** |
| **AURA（SCA 強化版）** | **~280–320 GE** | **✓** | **上記 + サイドチャネル強化** |

本表は面積と適合性の比較であり、**機能の等価性を示すものではありません**。AURA は異なる階層に位置します。TPM と保証等級を競うのではなく、そもそも TPM を選択肢にできなかった設計を対象としています。

**ゲート数の基準：** 182 GE はベース版 HRoT の FPGA 実測値（Vivado 2023.2、Artix-7 35T：46 LUT + 22 FF）。~280–320 GE は 4 層 SCA をすべて有効化した場合（FPGA 実測）。28nm ASIC は約 300–500 GE の**推定値**であり、実シリコンでの測定値ではありません。

## コア機構

標準的なバイナリ CMOS 上での三値状態エンコーディング。特殊プロセスは不要です。

| 状態 | 意味 | 挙動 |
|---|---|---|
| `2'b01` | 正当 | 通常動作 |
| `2'b10` | **隔離** | アクセス遮断。**正当な所有者は資格情報の検証により復旧可能** |
| `2'b11` | 不正 / アラート | 異常または SEU イベントを検知 |

**重要な性質：** `2'b10` が MAC チェーンに入ると、いかなるソフトウェア命令でも解除できません。復旧はハードウェアで定義された経路上での資格情報検証によってのみ可能です。

**これは意図的な設計であり、文鎮化ではありません。** 製品所有者にとって隔離イベントは、明確な復旧手順を持つ保守可能な状態です。復旧可能であるため、返品対応ではなくサポート業務として運用できます。一方、クローン品を保持する攻撃者にとっては、ソフトウェア経由の復帰経路は存在しません。

## 4 層サイドチャネル強化

| 層 | 機構 | 対象 |
|---|---|---|
| L1 | マスク付き LFSR | 電力差分解析（DPA） |
| L2 | デュアルレール論理 | DPA、フォールトインジェクション、SEU（0 サイクル検出） |
| L3 | 定時間 MAC | タイミングサイドチャネル |
| L4 | ランダム遅延挿入 | DPA トレース整列 |

4 層すべて RTL で実装されており、ファームウェアに依存しません。

> **検証ステータス。** 上記の機構は実装済みで、機能シミュレーションによる検証を完了しています。**物理サイドチャネル評価（TVLA、ISO/IEC 17825 準拠）は現在実施中です。** そのデータを本リポジトリで公開するまでは、実測による攻撃耐性の主張は検証済みとみなすべきではありません。評価者に発見されるより先に、この点を自ら明示します。

## 想定ユーザー

**FPGA ベースの機器メーカー** — 産業用コントローラ、計測器、医療・試験機器など、基板コピーに直面している製品。既存ハードウェアにそのまま実装可能で、再流動（respin）は不要です。**これが現時点での最優先領域です。**

**IoT・組込みシリコン** — スマートロックや高セキュリティ端末など、フルセキュリティサブシステムが面積・電力予算に収まらない設計。EU EN 18031 は無線機器指令（RED）の下で 2025 年 8 月より適用開始。SESIP L2 認証パスに対応します。

**車載** — 4 層 SCA 強化は ISO 21434 のハードウェア前提条件に対応し、ECU シリコンへの面積増加は僅少です。認証サイクルが長いため、短期ではなく戦略的な経路として推進します。

**RISC-V SoC プロジェクト** — AMBA APB 統合ラッパーを開発中。
