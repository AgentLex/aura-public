## 業界の課題

チッククローンによる年間損失は約**420億ドル**。現在のほとんどのチップはファームウェア層で認証を行っており、ソフトウェアを制御できる者がチップのIDを制御できてしまいます。

既存のソリューションは、問題が最も深刻な場所に組み込めません：

| ソリューション | ゲート数 | MCU/IoT組み込み可否 | 耐DPA性 | 耐SEU性 |
|---|---|---|---|---|
| TPM 2.0 | ~50,000 GE | ✗ 大きすぎる | ✗ | ✗ |
| ARM TrustZone | SWオーバーヘッド | 部分的 | ✗ | ✗ |
| PUF単体 | ~10,000 GE | 部分的 | ✗ | ✗ |
| **AURA（Base）** | **182 GE** | **✓ 完全適合** | **✓ 4層防御** | **✓ L2デュアルレール** |
| **AURA（SCA強化版）** | **~280–320 GE** | **✓ 完全適合** | **✓ 4層全有効** | **✓ L2デュアルレール** |

> **ゲート数の説明：** 182 GE = Base HRoT（FPGA実測：Vivado 2023.2, Artix-7 35T: 46 LUT + 22 FF）。~280–320 GE = 4層SCA全有効（FPGA）。ASIC @ 28nm 推定約300–500 GE。
>
> AES-128単体の最小ハードウェア実装は約**2,400 GE**。SCA強化版AURAでさえ、AES-128の約13%の面積で、IDバインディング + クローン防止 + 4層SCA防御を実現します。

## コアメカニズム

標準2値CMOSで3値状態エンコーディングを実現——**特殊プロセス不要**。

```
2'b01 → 正規 · 通過   通常動作
2'b10 → 隔離 · 保護   未認証アクセスを永続的にブロック；正規オーナーは認証で回復可能
2'b11 → 不正 · アラート   異常検出 / SEUイベント
```

> **核心：** `2'b10` がMACチェーンに注入されると、どのソフトウェア命令もクリアできません。
> これはハードウェアの制約であり、ファームウェアフラグやソフトウェアenumとは根本的に異なります。

## 4層サイドチャネル防御

| レイヤー | メカニズム | 防御対象 |
|---|---|---|
| L1 | マスクLFSR | DPA — 攻撃複雑度 O(2³²) → O(2⁴⁸) |
| L2 | デュアルレール論理 | DPA + 故障注入 + SEU（0サイクル検出） |
| L3 | 定数時間MAC | タイミングサイドチャネル漏洩 |
| L4 | ランダム遅延挿入 | DPAトレースアライメント（約100倍困難化） |

4層すべてがRTLレベルで実装——**ファームウェア依存なし**。
