## コアメカニズム

標準バイナリCMOS上での3値状態エンコーディング — **特殊プロセス不要**。

```
2'b01  →  正規 · 通過       通常動作
2'b10  →  隔離 · 保護       不正アクセスは永遠にブロック；正規所有者は認証後に復旧可能
2'b11  →  不正 · アラート   異常 / SEUイベント検出
```

> **重要な洞察：** `2'b10` が一度MACチェーンに注入されると、いかなるソフトウェア命令もクリアできません。  
> これはハードウェア制約であり、ファームウェアフラグやソフトウェアenumとは本質的に異なります。

## 4層サイドチャネル防御

| 層 | メカニズム | 防御対象 |
|---|---|---|
| L1 | マスクLFSR | DPA — 複雑度 O(2³²) → O(2⁴⁸) |
| L2 | デュアルレール論理 | DPA + 故障注入 + SEU（0サイクル検出） |
| L3 | 定数時間MAC | タイミングサイドチャネル |
| L4 | ランダム遅延挿入 | DPAトレースアライメント（約100倍困難化） |

4層すべてRTLレベルで実装 — **ファームウェア依存なし**。

## ユースケース

**スマートロック / 高セキュリティIoT**  
182 GEはあらゆるロックMCUに組み込み可能。SESIP L2認証パスに対応。

**車載電子部品 / ASIL-D / ISO 21434**  
4層SCA防御はISO 21434のハードウェア要件を満たします。ECUシリコンへの面積オーバーヘッド < 0.002 mm²。

**産業用コントローラー / 防衛エレクトロニクス**  
FPGAバージョン即日利用可能。IDバインディングによるサプライチェーン偽造防止。
