## 產業痛點

絕大多數嵌入式裝置的身分認證發生在韌體層——控制了軟體的人，也就控制了裝置身分。對於基於 FPGA 的工業設備與成本敏感的物聯網終端，整板抄襲是長期存在的商業問題，而現有對策皆不理想：

- **位元流加密**：主流 FPGA 系列的位元流加密已有公開的側通道攻擊研究。
- **外掛認證晶片**：成本低，但匯流排暴露，易被中間人攻擊繞過。
- **完整安全子系統**（TPM、安全元件、商用 RoT IP）：其架構與定價面向高保障等級晶片，放不進真正發生抄襲的那類裝置的面積、功耗與授權預算。

AURA 針對的正是這個空檔：將身分綁定直接置於邏輯本身，且面積小到可與主應用共存。

## AURA 是什麼，不是什麼

AURA 是**身分與狀態錨點**，不是密碼運算引擎，也不是 TPM 的替代品。

**它提供：** 裝置身分綁定、複製偵測、軟體無法清除的硬體隔離態、SEU 異常偵測。

**它不提供：** 通用加解密、安全元件等級的金鑰儲存、經認證的密碼演算法庫，目前亦不具備 CC 保障等級。

與相鄰技術的定位對比：

| | 面積量級 | 可嵌入 MCU / 小型 FPGA | 主要功能 |
|---|---|---|---|
| TPM 2.0 | ~50,000 GE | ✗ | 完整安全子系統 |
| 商用 RoT IP（tRoot / RT 系列 / PUFrt 類） | 數千 GE | 部分 | 開機完整性 + 金鑰管理 |
| 單獨 PUF 巨集 | ~10,000 GE | 部分 | 不可複製金鑰源 |
| 外掛認證晶片 | 獨立元件 | ✓ | 挑戰回應認證（匯流排暴露） |
| **AURA（基礎版）** | **182 GE** | **✓** | **身分綁定 + 隔離態** |
| **AURA（SCA 加固版）** | **~280–320 GE** | **✓** | **同上，增加側通道加固** |

本表比較的是面積與適配性，**並非功能等價性**。AURA 處於不同層級：它並非在保障等級上與 TPM 競爭，而是面向那些從一開始就裝不下 TPM 的設計。

**閘數口徑：** 182 GE 為基礎版 HRoT，FPGA 實測（Vivado 2023.2，Artix-7 35T：46 LUT + 22 FF）。~280–320 GE 為四層 SCA 全部啟用（FPGA 實測）。28nm ASIC 估算約 300–500 GE——為估算值，非流片實測。

## 核心機制

在標準二進位 CMOS 上實現三態編碼——無需特殊製程。

| 狀態 | 含義 | 行為 |
|---|---|---|
| `2'b01` | 合法 | 正常運作 |
| `2'b10` | **隔離** | 存取阻斷；**授權方可憑憑證驗證恢復** |
| `2'b11` | 非法 / 告警 | 偵測到異常或 SEU 事件 |

**關鍵特性：** `2'b10` 一旦進入 MAC 鏈，任何軟體指令皆無法清除。恢復只能透過硬體定義的路徑完成憑證驗證。

**這是刻意設計，且並非變磚。** 對產品方而言，隔離事件是一個有明確恢復流程的可服務狀態——因為可恢復，它能作為售後流程營運，而非一次退貨。對持有複製件的攻擊者而言，不存在任何軟體層面的回路。

## 四層側通道加固

| 層 | 機制 | 針對 |
|---|---|---|
| L1 | 遮罩 LFSR | 差分功耗分析（DPA） |
| L2 | 雙軌邏輯 | DPA、故障注入、SEU（0 週期偵出） |
| L3 | 恆定時間 MAC | 時序側通道 |
| L4 | 隨機延遲插入 | DPA 軌跡對齊 |

四層全部在 RTL 層實現，不依賴韌體。

> **驗證狀態說明。** 上述機制已實作並通過功能模擬驗證。**物理側通道評估（TVLA，依據 ISO/IEC 17825）正在進行中。** 在該數據公布之前，任何「已實測抗攻擊能力」的表述皆不應視為已驗證。我們選擇主動寫明這一點，而非等評估方自行發現。

## 目標應用

**FPGA 整機製造商** — 工業控制器、儀器儀表、醫療與檢測設備等面臨整板抄襲問題的產品。可直接部署於現有硬體，無需重新流片。**這是我們當前的首要方向。**

**物聯網與嵌入式晶片** — 智慧鎖及高安全終端，尤其是裝不下完整安全子系統的面積／功耗預算場景。歐盟 EN 18031 已於 2025 年 8 月在無線電設備指令（RED）下開始適用；SESIP L2 為已支援的認證路徑。

**汽車電子** — 四層 SCA 加固對應 ISO 21434 的硬體前置要求，對 ECU 矽面積的增加極小。認證週期較長，作為策略路徑而非近期路徑推進。

**RISC-V SoC 專案** — AMBA APB 整合封裝開發中。
